# Kommo CRM Chat Parser

Инструмент для выгрузки и обработки истории переписок из **Kommo CRM** с последующей загрузкой данных в базу данных.

## Как это работает

Процесс состоит из трёх последовательных этапов:

```text
Kommo CRM
    ↓
parse_chats
    ↓
HTML-файлы
    ↓
kommo_export_chats
    ↓
JSON-файлы
    ↓
upload_to_db
    ↓
Database

## Этапы обработки
1. parse_chats

Проходит по лидам выбранной воронки в Kommo CRM и экспортирует каждый лид в отдельный HTML-файл.

2. kommo_export_chats

Обрабатывает HTML-файлы, извлекает из них историю переписки и сохраняет данные в JSON-файлы.

3. upload_to_db

Проходит по JSON-файлам и загружает содержащиеся в них данные в базу данных.

## Результат

Данные проходят следующий pipeline:

Kommo CRM → HTML → JSON → Database

Разделение процесса на несколько этапов позволяет независимо повторно обрабатывать уже выгруженные данные и не обращаться к Kommo CRM при каждом запуске последующих этапов.
